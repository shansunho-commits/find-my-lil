# Find My LIL v3

V2를 보존하고 아래 내용을 추가한 시험 버전입니다.

## V3 변경사항

- 궐련형 전자담배 경로에 Q5 `선호하는 스틱 맛` 추가
- 궐련형 전자담배 경로에 Q6 `선호하는 맛의 강도` 추가
- 궐련형 추천은 현재 기기보다 스틱 맛과 강도를 핵심 기준으로 계산
- 현재 기기, 만족 요소, 아쉬운 점은 상담 문구 또는 보조 점수로만 사용
- 결과 제목을 `회원님의 릴 스틱 추천 TOP 3`로 변경
- 1위 제품 카드에 선택한 취향을 기반으로 추천 이유 표시
- 결과 하단을 `릴 기기 할인 혜택` 영역으로 변경
- 버튼 문구를 `직원에게 화면 보여주기`로 변경
- 팝업 문구를 `직원에게 이 화면을 보여주세요.`로 통일
- 추천코드 및 행사 직원이라는 표현은 사용하지 않음

## 실행 방법

압축을 푼 후 `index.html`을 Edge 또는 Chrome으로 실행하세요.

## 참고

V3는 방향 확인용 버전입니다. 추천 이유, 질문 순서, 점수, 문구 또는 화면 구성이 마음에 들지 않으면 이 버전을 기준으로 다시 조정할 수 있습니다.
