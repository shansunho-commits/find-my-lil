# Find My LIL Analytics v1

Team Review 버전에 로컬 분석모드를 추가한 버전입니다.

## 분석모드 여는 방법

1. 첫 화면 하단 `Powered by KT&G LIL`을 빠르게 5번 누릅니다.
2. 관리자 비밀번호 `1234`를 입력합니다.
3. 현재 기기에 저장된 분석 대시보드가 열립니다.

## 집계 항목

- 총 완료 수
- 기기 추천 수와 비율
- 스틱 추천 수와 비율
- 에이블 3.0 / 하이브리드 3.0 추천 수와 비율
- 가장 많이 선택된 현재 제품
- 가장 많이 선택된 선호 맛
- 가장 많이 추천된 스틱
- 직원 화면을 연 횟수
- 최근 설문 완료 시각

## 데이터

- 브라우저 localStorage에 저장
- 같은 휴대폰/태블릿/브라우저에서만 집계
- CSV 다운로드 가능
- 데이터 초기화 가능
- 관리자 비밀번호: 1234
