# Find My LIL V6

팀장 컨펌을 위한 V6 실행 버전입니다.

## 기기 추천

모든 고객에게 `릴 에이블 3.0`을 추천합니다.

고객 답변은 결과를 변경하는 점수로 사용하지 않고, 에이블 3.0을 설명하기 위한 상담 정보와 분석 데이터로 활용합니다.

### 질문

- 성별: 남성 / 여성
- 연령대: 20대 / 30대 / 40대 / 50대 이상
- 현재 제품:
  - 연초
  - 아이코스 일루마
  - 플룸
  - 글로 하이퍼
  - 릴 하이브리드
  - 액상형 전자담배
- 중요 요소:
  - 빠른 예열
  - 풍부한 연무
  - 담배와 비슷한 만족감
  - 간편한 사용
  - 가격
- 하루 사용량
- 선호 사용감

## 스틱 추천

- 멘솔 계열
  - 강한 멘솔: 에임 아이스피크 / 에임 아이스팟 / 레임 아이스
  - 부드러운 멘솔: 레임 아이스미드 / 에임 쿨샷 / 에임 탱고
  - 타격감 있는 멘솔: 레임 아이스 / 에임 아이스피크 / 에임 쿨샷
- 향 계열:
  - 에임 트와이스 / 에임 블루밍 / 에임 리믹스
- 오리지널 계열:
  - 에임 시가리쉬 / 에임 까메오 / 레임 레귤러

제품은 1위·2위·3위 순위 없이 동등한 카드로 표시합니다.

## 이미지

사용자가 제공한 현장 안내판 사진에서 다음 제품 이미지를 가공하여 반영했습니다.

- 에임 아이스팟
- 에임 리믹스

사진 원본 특성상 다른 공식 제품 이미지보다 해상도와 배경 품질에 차이가 있을 수 있습니다.

## 직원 모드

- `직원에게 화면 보여주기`
- 비밀번호: `1234`

## 분석 모드

- 첫 화면 `Powered by KT&G LIL`을 빠르게 5번 누르기
- 비밀번호: `1234`
- 성별·연령대·현재 제품별 인원과 비율
- 주요 선택 항목
- 스틱 계열과 안내 제품
- CSV 다운로드


## V6.1 변경사항

- 모든 질문 카드 하단에 `← 이전 질문` 버튼 추가
- 첫 질문에서 누르면 메인 화면으로 이동
- 이후 질문에서는 직전 문항으로 이동하고 기존 답변을 다시 선택 가능
- 상단의 기존 이전 버튼도 유지


## V6.2 디자인 리마스터

- 질문별 이모지 전면 적용
- 선택지마다 서로 다른 아이콘 사용
- 시작 화면 기기/스틱 카드 아이콘 개선
- 첫 화면 `30초 만에` 문구와 반짝임 장식 추가
- 버튼 크기 확대
- 선택 시 체크 표시와 팝 애니메이션 적용
- 선택하지 않은 항목은 잠시 흐려지는 효과
- 결과 제품 카드 확대 및 그림자 개선
- 직원모드 고객 정보·상담 포인트·상담 멘트 아이콘 추가
- 분석모드 성별·연령·제품·선택 현황 아이콘 추가
- 분석 진행 막대와 결과 카드의 시각적 완성도 개선


## V6.2.1 변경사항

- 첫 화면 반짝이 별 장식 제거
- 결과 화면 상단 반짝이 장식 제거
- 하루 사용량 선택지의 이모지를 모두 담배 1개로 통일
- 이모지가 선택 카드 테두리 밖으로 넘치지 않도록 보강


## V6.3 Minimal 변경사항

- 컬러 이모지를 모두 제거
- 질문 및 선택지 아이콘을 단색 SVG 라인 아이콘으로 교체
- 아이콘 색상을 릴 브랜드 하늘색 계열로 통일
- 성별, 연령, 제품, 가격, 사용감 등 선택지별 의미는 유지
- 첫 화면 기기/스틱 카드도 단색 라인 아이콘 사용
- 직원모드와 분석모드 제목의 이모지 제거
- 귀여운 느낌보다 전문 상담 도구에 가까운 미니멀 디자인 적용


## 컨펌용 이미지 처리

- 에임 아이스팟 이미지 제거
- 에임 리믹스 이미지 제거
- 두 제품 모두 `이미지 준비중` 플레이스홀더로 표시
- 공식 이미지 확보 후 교체 예정
