# Find My LIL — Team Review

팀장 컨펌용 최종 시연 버전입니다.

## 주요 기능

- 릴 기기 추천과 릴 스틱 추천 통합
- 첫 화면 좌우 선택 카드
- 첫 화면 하단 `Powered by KT&G LIL` 소형 표기
- 단계별 분석 문구와 분석 체크리스트
- 추천 결과와 고객 선택 표시
- 직원 상담 포인트와 추천 멘트
- 함께 소개할 제품의 비교 제안 멘트
- 직원 비밀번호 `1234`
- 비밀번호 인증 후 STAFF MODE 진입
- 다크모드 미포함
- 모바일·태블릿·PC 반응형 화면

## 테스트 순서

1. 기기 추천 완료
2. 직원에게 화면 보여주기
3. 비밀번호 `1234`
4. 추천 결과, 고객 선택, 상담 포인트, 추천 멘트, 비교 제안 확인
5. 스틱 추천도 동일하게 테스트
